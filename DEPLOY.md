# Guía para Publicar el Sitio de "Lilith be Chamberi" en Internet GRATIS

Aquí te mostramos dos opciones sencillas para publicar tu sitio web de manera gratuita. No necesitas ser un experto en tecnología. ¡Vamos a ello!

## OPCIÓN A: Netlify (Recomendada, Gratis)

1. **Crea una cuenta en Netlify:**
   - Ve a [netlify.com](https://www.netlify.com) y regístrate con tu correo electrónico.

2. **Sube tu sitio web:**
   - Haz clic en "New site from Git" y conecta tu cuenta de GitHub (o GitLab/Bitbucket si prefieres).

3. **Selecciona el repositorio:**
   - Escoge el repositorio que contiene tu sitio web y haz clic en "Deploy Site".

4. **Espera la publicación:**
   - Netlify hará todo el trabajo por ti. Espera unos minutos a que tu sitio esté en línea.

5. **Obtén tu enlace:**
   - Una vez publicado, recibirás un enlace con el que podrás compartir tu sitio con el mundo.

## OPCIÓN B: GitHub Pages (También Gratis)

1. **Crea una cuenta en GitHub:**
   - Ve a [github.com](https://github.com) y regístrate con tu correo electrónico.

2. **Crea un nuevo repositorio:**
   - Haz clic en "New" para crear un repositorio. Nómbralo como "username.github.io" (cambia "username" por tu nombre de usuario).

3. **Sube tus archivos:**
   - Sube los archivos de tu sitio web al nuevo repositorio.

4. **Activa GitHub Pages:**
   - Ve a "Settings" en tu repositorio, desplázate hasta "Pages" y selecciona la rama "main" para la fuente de publicación.

5. **Visita tu sitio:**
   - Espera unos minutos y luego visita "https://username.github.io" para ver tu sitio en vivo.

## Nota sobre el Dominio Propio

- **Cuándo comprar un dominio propio:**
  - Si deseas una dirección web más profesional y fácil de recordar (por ejemplo, "lilithbechamberi.com"), considera comprar un dominio. Esto suele tener un costo anual. Puedes hacerlo a través de proveedores como Google Domains, GoDaddy, o Namecheap.
