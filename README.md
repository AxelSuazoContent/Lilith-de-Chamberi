# Bienvenido a tu tienda web de "Lilith be Chamberi" 🌸

¡Hola! Este archivo es tu guía simple y amigable para manejar tu tienda web. No te preocupes, no necesitas saber de programación. Vamos paso a paso. 😊

## 1. ¿Qué es esta carpeta? 📁

Aquí vive tu tienda web. Todo lo que necesitas para mostrar tus productos está aquí dentro. ¡Es como el corazón digital de tu negocio!

## 2. ¿Cómo ver mi tienda? 👀

Para ver cómo se ve tu tienda:

1. **Opción 1:** Haz doble clic en el archivo llamado `index.html`. Esto abrirá tu tienda en tu navegador de internet (como Chrome o Firefox).
   
2. **Opción 2:** Puedes subir tu tienda a un sitio como [Netlify](https://netlify.com). Allí, solo sigues unos pasos sencillos y tu tienda estará en línea para que todos la vean.

## 3. ¿Cómo agregar o editar productos? 🛍️

Para hacer cambios en tus productos:

1. Abre el archivo `products.js` usando un programa sencillo como el Bloc de Notas o el programa gratuito [VS Code](https://code.visualstudio.com/).

2. Cada producto está dentro de este archivo y se ve algo así:

   ```javascript
   {
     name: "Crema Facial",
     price: 20,
     desc: "Crema hidratante para todo tipo de piel.",
     emoji: "🧴",
     photo: "enlace_a_la_imagen",
     sizes: ["S", "M", "L"] // Este es opcional, solo si vendes por tallas
   }
   ```

3. Edita los campos como `name` (nombre), `price` (precio), `desc` (descripción), `emoji` (emoji), y `photo` (enlace a la foto).

4. Guarda tus cambios y recarga tu navegador para ver cómo se ve.

## 4. ¿Cómo subir fotos de mis productos? 📸

Las fotos de tus productos se suben a internet. Aquí te explico cómo hacerlo:

1. Sube tus fotos a un lugar como [Google Drive](https://drive.google.com) o [Imgur](https://imgur.com).

2. Copia el enlace de la imagen que subiste.

3. Pega este enlace en el campo `photo` de tu producto en el archivo `products.js`.

   - Si tu producto tiene variantes de color, pega el enlace dentro de `colors`.

## 5. ¿Cómo cambiar el número de WhatsApp? 📞

Para actualizar tu número de WhatsApp:

1. Abre el archivo `index.html`.

2. Busca la palabra `WA_NUM` (puedes usar la función de búsqueda de tu programa).

3. Reemplaza el número que ves ahí con tu nuevo número de WhatsApp.

## 6. Preguntas frecuentes ❓

**¿Qué pasa si hago un cambio y no lo veo?**
- Asegúrate de guardar los cambios y recargar tu navegador.

**¿Puedo usar cualquier imagen para mis productos?**
- Sí, siempre y cuando tengas el enlace de la imagen en internet.

**¿Qué hago si me pierdo?**
- No te preocupes, sigue los pasos de nuevo o busca ayuda.
